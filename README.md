# Personal Smart Healthcare Assistant

## Project Description
The Personal Smart Healthcare Assistant is a Java Swing-based desktop application designed to help users monitor daily health vitals and receive basic health feedback.

## Technologies Used
- Java
- Java Swing
- Object-Oriented Programming
- File Handling

## Main Features
1. Daily health vitals input.
2. Heart rate monitoring.
3. Blood pressure monitoring.
4. Water intake tracking.
5. Sleep duration tracking.
6. Wellness score calculation.
7. Health status and feedback.
8. Morning and evening medication reminders.
9. Save daily health records in a text file.
10. Reset button to clear current entries.

## Project Structure
- `SmartHealthGUI.java` – Main graphical user interface.
- `VitalsModel.java` – Health calculations and evaluation.
- `FileManager.java` – Saves health records into a text file.

## How to Run
1. Install Java JDK.
2. Download and extract the project ZIP.
3. Open the project folder in VS Code.
4. Compile:

   `javac SmartHealthGUI.java VitalsModel.java FileManager.java`

5. Run:

   `java SmartHealthGUI`

## Conclusion
This project demonstrates Java Swing, object-oriented programming and file handling through a simple personal healthcare assistant.
